PA MedLog Talent LLC — Version 10.1 Email Notifications

Website enquiry behavior:
- Every successful enquiry is stored in WordPress Lead Center.
- A notification is sent to hr@pamedlogtalent.com.
- Reply-To is set to the visitor email so the team can reply directly.
- The visitor receives a short acknowledgement email.
- Lead Center shows whether the admin notification was Sent or Failed.

IMPORTANT DELIVERY SETUP
WordPress wp_mail() needs a correctly configured mail transport. For production, configure authenticated SMTP using your Hostinger mailbox or a transactional email provider. Configure SPF, DKIM and DMARC for pamedlogtalent.com. Theme code cannot guarantee inbox delivery without working mail transport/DNS.

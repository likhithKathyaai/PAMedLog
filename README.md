# PA MedLog Talent LLC — React Website

Production React/Vite website for PA MedLog Talent LLC.

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm install
npm run build
```

Deploy the contents of `dist/` to the web root. The included `public/.htaccess` is copied into `dist/` and provides Apache SPA fallback routing for React Router.

## Security
Never commit API keys, SMTP credentials, .env files, or other secrets. KATHYA AI and enquiry delivery must use secure server-side endpoints.
